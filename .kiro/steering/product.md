# Product Overview

**Lunumia** is a personal finance application designed to help users track expenses, manage budgets, and gain clarity over their spending habits.

## Core Purpose

- Provide clear visibility into personal spending
- Help users categorize and track expenses
- Support budgeting and financial goal-setting

## Target Users

- Individuals managing personal finances
- Users who want a simple, clear view of where their money goes

## Language

- The product name is in Spanish ("gasto" = expense, "claro" = clear)
- UI language and user-facing content: TBD (Spanish, English, or bilingual)

## Key Principles

- Simplicity: Keep the interface and workflows straightforward
- Clarity: Present financial data in an easy-to-understand way
- Privacy: User financial data must be handled securely
