Aviso de Privacidad Integral de Lunumia

Última actualización: 24 de noviembre de 2026

Este Aviso de Privacidad describe cómo se tratan los datos personales en la aplicación móvil, aplicación web progresiva y servicios relacionados ofrecidos bajo la marca Lunumia (la “Plataforma”).

2. Datos personales que podemos tratar

  • Cuenta: correo electrónico, identificador de cuenta y, si se proporciona, nombre o datos de perfil administrados mediante el servicio de autenticación.
  • Información financiera ingresada: ingresos, gastos, categorías, fechas, presupuestos, compromisos de pago, saldos, metas y preferencias relacionadas con la organización financiera. No solicitamos acceso a cuentas bancarias ni credenciales bancarias.
  • Recibos: imagen seleccionada para lectura automatizada y datos visibles que pueden extraerse, como comercio, fecha, moneda y monto. La imagen comprimida se procesa durante la solicitud; la aplicación no la conserva como parte del gasto ni del respaldo, y el texto OCR crudo no se persiste por Lunumia.
  • Datos técnicos necesarios: información de sesión, identificadores técnicos, registros mínimos de operación, seguridad, límites de uso y errores. No introduzcas en campos libres datos personales de terceros que no sean necesarios.
  • Datos de contacto que envíes voluntariamente: contenido de mensajes de soporte y datos que incluyas en ellos.

Los datos financieros o patrimoniales pueden tener protección especial conforme a la legislación aplicable. Lunumia no solicita deliberadamente datos personales sensibles. Si el Usuario los incluye en recibos, texto o mensajes, se tratarán incidentalmente para prestar la función solicitada; evita incluirlos cuando no sean necesarios.

3. Datos locales, cuenta y sincronización

La aplicación puede utilizarse como invitado. En ese modo, los registros principales se almacenan en el navegador o dispositivo mediante almacenamiento local, incluido IndexedDB. Lunumia no recibe esos registros por sincronización mientras esta no se habilite; el proveedor de alojamiento de la aplicación puede recibir los datos técnicos de conexión necesarios para entregar la página.

Al crear una cuenta y utilizar las funciones de sincronización, los datos financieros que el Usuario elija mantener en su cuenta se transmiten a la infraestructura de Supabase configurada por Lunumia para autenticación, almacenamiento y sincronización. Los registros también pueden permanecer en el dispositivo para que las funciones locales y offline sigan disponibles. La sincronización puede requerir conexión a Internet.

El almacenamiento local de la aplicación no está cifrado por Lunumia como una base cifrada independiente. El acceso a ese almacenamiento puede ser posible para alguien con acceso al perfil del navegador o al dispositivo. Se recomienda proteger el dispositivo, cerrar sesiones en equipos compartidos y conservar respaldos propios.

4. Finalidades del tratamiento

Finalidades necesarias para el servicio:

  • Crear y autenticar cuentas, mantener sesiones y proteger el acceso.
  • Guardar, organizar, calcular, mostrar, respaldar y sincronizar los registros que el Usuario ingrese.
  • Procesar, cuando el Usuario lo solicita, imágenes de recibos para proponer datos editables, y generar resúmenes, clasificaciones o análisis automatizados.
  • Atender solicitudes de soporte, gestionar exportaciones y tramitar el cierre de cuenta y solicitudes de privacidad.
  • Prevenir abuso, investigar incidentes, mantener la seguridad y disponibilidad, aplicar límites de uso y cumplir obligaciones legales.

Finalidades secundarias: Lunumia no usa actualmente los datos financieros personales para publicidad comportamental ni para entrenar modelos de inteligencia artificial. No se realizan finalidades secundarias con los datos financieros bajo este Aviso. Si se propone una nueva finalidad secundaria, se actualizará este Aviso y se obtendrá el consentimiento correspondiente cuando la ley lo requiera.

5. Procesamiento mediante inteligencia artificial y recibos

Las funciones de IA y OCR son opcionales y se ejecutan cuando el Usuario las solicita. Para generar sugerencias o resúmenes, se envía a una función de servidor de Supabase el contexto estrictamente necesario de los registros seleccionados para esa solicitud. La función puede transmitir ese contexto al proveedor Groq y al modelo configurado para generar una respuesta. Lunumia valida la respuesta y la devuelve a la aplicación.

Para leer un recibo, la imagen comprimida se envía desde el dispositivo a una función de Supabase y de ahí al proveedor de IA multimodal configurado (actualmente Groq con un modelo compatible con Qwen). Lunumia no persiste la imagen, el prompt completo, la respuesta cruda ni el texto OCR crudo. La imagen permanece temporalmente en memoria durante el flujo de captura y revisión; el resultado sugerido se muestra para que el Usuario lo corrija y confirme. Al confirmar, los campos financieros aceptados se guardan como parte del registro de gasto.

Los proveedores externos procesan datos conforme a sus propias condiciones y políticas. Antes de habilitar estas funciones en producción, el Responsable debe verificar y documentar contractualmente las condiciones de uso, ubicación, transferencias, subencargados y retención aplicables de Supabase y Groq, y mantener esta información actualizada. Las respuestas automatizadas pueden ser inexactas y requieren revisión del Usuario.

6. Transferencias y encargados

Para prestar el servicio, el Responsable utiliza proveedores que tratan datos por cuenta de Lunumia o reciben datos necesarios para ejecutar la función solicitada, entre ellos:

  • Supabase: autenticación, infraestructura de base de datos, funciones de servidor y sincronización de la cuenta.
  • Groq: procesamiento de solicitudes de IA y reconocimiento de recibos cuando el Usuario solicita esas funciones.
  • Proveedor de alojamiento y distribución de la aplicación: entrega de la página y seguridad técnica del servicio.

Estos proveedores pueden operar infraestructura fuera de México. El Responsable deberá mantener disponible la lista y ubicación aplicable de proveedores y subencargados, así como identificar en el Aviso cualquier transferencia a terceros que no actúen como encargados y obtener el consentimiento requerido. Los datos no se venden. También podrán comunicarse a autoridades cuando exista requerimiento legal válido.

Detalle operativo pendiente de confirmar antes de publicar: razón social, país o región de tratamiento y enlaces a los avisos/condiciones vigentes de cada proveedor; identificar si existe algún proveedor publicitario, analítico, de correo o de soporte que reciba datos personales. No incluir proveedores que no se utilicen realmente.

7. Consentimiento para datos financieros

Cuando la legislación lo requiera, el Responsable solicitará consentimiento expreso para tratar datos financieros o patrimoniales, mediante una acción afirmativa e informada separada de la mera navegación. La solicitud indicará qué datos se tratarán y para qué finalidades. El consentimiento podrá revocarse siguiendo el procedimiento de la sección 9; la revocación no tendrá efectos retroactivos y puede impedir funciones que dependan del tratamiento.

Este texto no sustituye el mecanismo visible de consentimiento en el registro o antes de sincronizar y usar IA. El Responsable debe implementar y conservar evidencia de esa aceptación antes de habilitar el tratamiento correspondiente.

8. Conservación y eliminación

Los datos se conservan mientras sean necesarios para las finalidades descritas, exista una cuenta activa o haya una obligación legal aplicable. Al solicitar el cierre, Lunumia elimina los datos de cuenta y registros remotos mediante el flujo de eliminación disponible; los datos locales guardados en el dispositivo pueden requerir eliminación separada desde la aplicación o el dispositivo.

Copias de seguridad técnicas pueden permanecer durante el ciclo normal de rotación y se sobrescriben o eliminan de acuerdo con los controles del proveedor. Datos mínimos pueden conservarse bloqueados cuando sean necesarios para cumplir obligaciones o atender responsabilidades legales, y después se eliminan o disocian.

9. Derechos ARCO y revocación del consentimiento

El Usuario puede solicitar acceso, rectificación, cancelación u oposición (derechos ARCO), así como revocar su consentimiento o solicitar limitación del uso o divulgación cuando proceda, enviando un correo a legal@lunumia.com con el asunto “Privacidad — derechos ARCO”.

La solicitud debe incluir: nombre del titular y medio para comunicar la respuesta; documentos que acrediten identidad y, en su caso, representación; descripción clara del derecho que desea ejercer y de los datos involucrados; y cualquier elemento que ayude a localizar la información. El Responsable podrá pedir información adicional para verificar identidad o precisar la solicitud. Responderá dentro de los plazos previstos por la legislación aplicable.

La cancelación puede estar sujeta a periodos de bloqueo o conservación legal. La revocación no afecta tratamientos realizados previamente y puede hacer que algunas funciones dejen de estar disponibles. Para solicitar eliminación de una cuenta, el Usuario también puede utilizar la opción de eliminación dentro de la aplicación cuando esté disponible.

10. Seguridad

El Responsable aplica controles técnicos y organizativos razonables, como autenticación, separación de cuentas y permisos de acceso, controles de seguridad de infraestructura y límites contra abuso. Ningún medio de transmisión o almacenamiento es absolutamente infalible. En caso de una vulneración que afecte significativamente los derechos patrimoniales o morales de titulares, se les informará conforme a la legislación aplicable.

11. Cookies y almacenamiento del navegador

La aplicación puede usar almacenamiento local e IndexedDB para guardar preferencias y datos que permiten funcionar localmente; la sesión de autenticación también puede persistir en el almacenamiento configurado por el proveedor de autenticación. La landing guarda la preferencia de apariencia en almacenamiento local. No se declaran cookies publicitarias ni analítica de terceros en este Aviso. Si se incorporan, se actualizará el Aviso y se implementarán los controles de consentimiento que correspondan.

12. Cambios al Aviso

El Responsable puede actualizar este Aviso para reflejar cambios en el servicio, proveedores, finalidades o requisitos legales. La versión vigente estará disponible en https://lunumia.com/privacy/, con su fecha de actualización. Los cambios sustanciales se comunicarán dentro de la Plataforma o al correo de cuenta con antelación razonable. Si un cambio requiere nuevo consentimiento, se solicitará antes de iniciar el tratamiento correspondiente.

13. Autoridad competente

El Usuario puede acudir a la Secretaría Anticorrupción y Buen Gobierno, autoridad competente en México en materia de protección de datos personales en posesión de particulares, conforme a la legislación vigente, sin perjuicio de contactar primero al Responsable.
